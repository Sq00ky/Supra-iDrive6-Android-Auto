# This file contains a list of coding requirements needed for Android Auto to work properly
These can be coded in using BimmerCode, BimmerUtility, esys, ProTool, or any other BMW Coding Apps
## HMI Plugin
**3000 HMI:**

REMOTE_HMI -> AKTIV

A4A -> AKTIV

A4A_REMOTE_APS -> AKTIV

## Bluetooth / ServiceRequestError
**3002 AUDIO_TUNER_TRAFFIC:**

A4A_ANDROID -> AKTIV

**3003 TELEFON_TELEMATIK_ONLINE:**

A4A_WIRELESS_ANDROID  -> AKTIV


## WiFi Direct
**3000 HMI:**

ENT_MIRACAST -> aktiv 

ENT_MC_WLAN_STREAM_DMP -> aktiv 

ENT_MIRACAST_DISPLAY_SETTINGS > aktiv 

WLAN_WIFI_DIRECT -> aktiv 

WLAN_STATUS -> aktiv

WLAN_AP -> aktiv

After that, go to Manage Mobile Devices -> Settings and make sure Vehicle WiFi is ticked
