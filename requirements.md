# Requirements
As of v1.8.66, the following is required:
1. Apple CarPlay
2. WiFi Antenna 
3. SSH Access to the NBT Evo Head Unit
4. **For Retrofits** - OADR/OABR on/to the Head Unit

## Installation Requirements
1. SSH access to the head unit
2. ODB to ENET cable

### NOT COMPATIBLE
1. **ODB WiFi/Bluetooth Adapter**

### OPTIONAL
1. Flash Drive in FAT32/exFAT for logging
